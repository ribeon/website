# Ribeon

> Cloud storage is now the default. Local data is retained as a backup. See the [shared storage setup](../storage/README.md) for authentication, dependencies and explicit local overrides.


Ribeon builds actionable alternative datasets from primary sources, mapped to tradeable instruments for institutional investors and quantitative researchers.

Visit [ribeon.com](https://ribeon.com) to learn more.


## Workspace data

Website sample and evidence payloads live in `../data/website/content/`, referenced through `src/lib/data/payloads`. Restore that folder and run `python3 bin/workspace_data.py` from the workspace root before building on another computer.
